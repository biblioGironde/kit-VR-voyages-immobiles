        Préparer un casque (une seule fois)
        1. Activer le mode développeur du casque dans l'application mobile Meta Horizon (Appareils › Paramètres › Mode développeur). Il faut un compte rattaché à une organisation développeur Meta.
        2. Brancher le casque à l'ordinateur avec un câble USB-C de données.
        3. Cliquer sur « Connecter un casque », choisir le Quest dans la liste, puis accepter le débogage USB dans le casque.
        4. Fermer SideQuest, Meta Quest Developer Hub ou tout autre outil adb : ils bloquent l'accès.

        Les vidéos ne quittent jamais l'ordinateur autrement que par le câble : aucun envoi sur internet.
